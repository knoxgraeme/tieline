# Initial grading experiments — 2026-10-05

Six fresh independent host-agent runs used neutral case IDs and the complete
evidence for each AC. Graders read only instructions, the rubric and evidence
packets, then saved original verdicts. They did not receive evaluator expectations
or implementation rationale, and did not execute product code or access network
or credentials. The host verified citations and scored their responses.

| Corpus and rubric | Runs | Cases passed per run | False support | Spurious link findings per run |
| --- | --- | --- | --- | --- |
| v1, initial rubric | 2 | 4/6 | 0 | 2 |
| v1, clarified link relevance | 2 | 5/6 | 0 | 0 |
| v2, separate irrelevant and unavailable evidence | 2 | 7/7 | 0 | 0 |

All runs detected the obsolete link and the prose mislabeled as implementation.
Both initial runs also labeled relevant but buggy implementations as wrong links.
The rubric now reserves link findings for locator problems; actual behavioral
defects belong in the AC judgment. Independent review also corrected the early
fixture expectations that had conflated those two findings before scoring.

Both next runs graded the notes-only case `unsupported` where v1 expected
`inconclusive`. Independent review identified an ambiguous fixture/rubric boundary:
the supplied artifact was irrelevant, while the actual implementation was absent.
Corpus v2 keeps the irrelevant-artifact case as `unsupported` and adds a separate
case with relevant code delegating behavior to an unavailable dependency, expected
`inconclusive`. The rubric states that distinction. The v1 failures remain
recorded; they were not rescored as successes using v2 expectations.

[Recorded scores](grading-2026-10-05.json) retain per-case outcomes and available
rubric receipts. The first prototype runs predate frozen-rubric receipts; the
later runs include the exact rubric hash. Engine version, cost and latency were
not instrumented. This small, iteratively refined corpus establishes regression
examples, not an unbiased general model-performance estimate.

Independent harness review reproduced extra-file injection and packet/rubric
tampering that originally escaped scoring. The harness now rejects those inputs,
checks the corpus version and exact scope cardinality, and includes regression
tests. `npm run test:grading-evaluation` uses canned verdicts solely to verify
these mechanics and does not invoke or evaluate a model.

Separately, an independent disposable-workspace forward test of the closeout
skill reproduced a confirmation bypass, fixed it, and observed the regression
test pass. It retained parser uncertainty and excluded a cosmetic heading change.
That is a manual workflow check; there is not yet an automated end-to-end agent
repair runner. Ordinary CI remains deterministic and model-free.
